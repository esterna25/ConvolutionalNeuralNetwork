# Convolutional Neural Network (CNN) for Detection of Fruits Images
## Introduction
Convolutional Neural Networks (CNNs) have been widely used for image classification tasks due to their ability to capture spatial hierarchies in images. This project aims to demonstrates the use of a CNN to classify images of fruits into three categories: Banana, Coconut, and Orange. The implementation involves training a CNN model on a dataset of fruit images and then using the trained model to classify new images.
## Goal
The primary objective of this project is to develop a robust Convolutional Neural Network (CNN) model for accurately classifying images of fruits into three distinct categories: Banana, Coconut, and Orange.
## Step-by-Step Process
**1. Data Loading and Preprocessing**
  *  Load and preprocess the dataset consisting of images of Bananas, Coconuts, and Oranges.
    
**2. Model Training**
  * Train a CNN model on the preprocessed dataset.

**3. Model Evaluation**
  * Evaluate the trained model using a separate test set.

**4. Model Saving**
  * Save the trained model and label binarizer for future use.
    
**5. Image Classification**
  * Classify new images using the trained model.

## Conclusion
In conclusion, this project has provided valuable insights into the development and application of Convolutional Neural Networks (CNNs) for image classification tasks, specifically in the context of fruit image recognition. By following these steps, we demonstrated a comprehensive approach to building a functional image classification system
